# 4. Profiling HIP Applications with AMD Tools (rocprofv3 / rocminfo)

This lesson shows how to profile a HIP application using **rocprofv3** (and device inspection with **rocminfo**).

In addition to CSV/JSON stats, we also export a **pftrace** timeline compatible with **https://ui.perfetto.dev** so you can visually inspect kernels, dispatches, and memory copies.

---

## Files
- `profiling_target_hip.cpp`: the workload used for profiling.
- `profile_hip.sh`: builds and runs rocprofv3 and exports **pftrace** + trace CSVs.

---

## Run the profiling (GPU node)
The script must run on the **GPU node** (example: `g1`).

```bash
cd 4-hip-profiling-amd-tools
bash profile_hip.sh
```

This produces outputs under `./rocprofv3_out/`:
- `rocprofv3_out_results.pftrace` ✅ Perfetto timeline
  - `rocprofv3_out_results.json`
  - `rocprofv3_out_*_stats.csv`
  - `rocprofv3_out_*_trace.csv`

---

## Step-by-step: rocprofv3 profiling

### 1) Tool usage
`rocprofv3` usage:
```bash
rocprofv3 [options] -- <application> [application options]
```

### 2) Important rule: `--stats` must be combined with tracing
If you want the rocprofv3 stats CSV/JSON outputs, you must use:
- `--stats`
- plus at least one tracing option (e.g. `--kernel-trace`).

### 3) What this exercise enables
This folder uses (in the script):
- `--stats`
- `--kernel-trace`
- `--hip-runtime-trace`
- `--memory-copy-trace`
- `--summary` (+ `--summary-output-file ...`)
- `-f pftrace json csv`

> Note: `rocprofv3` expects formats as **space-separated** values after `-f`.

---

## Output formats (what you will see)
Inside `rocprofv3_out/` you will typically find:
- `rocprofv3_out_results.pftrace` → timeline for `ui.perfetto.dev`
- `rocprofv3_out_*_stats.csv` → aggregated stats per domain (kernel dispatch, memory copies, HIP API, ...)
- `rocprofv3_out_*_trace.csv` → event-level traces

---

## Perfetto: load the rocprofv3 pftrace step-by-step

### A) Open Perfetto
Go to: https://ui.perfetto.dev

### B) Import the trace
1. Upload `rocprofv3_out_results.pftrace`.
2. Wait until the timeline appears.

### C) Explore
- Search for the kernel name `transform_kernel`.
- You should see multiple dispatch ranges (the profiling target launches the kernel many times).
- With `--memory-copy-trace`, you can correlate kernel execution with copy events.

## Perfetto analysis workflow tip
- Keep the original `*.pftrace` generated by rocprofv3.
- Import it in `ui.perfetto.dev`.
- Use search + zoom to find:
  - kernel dispatch intervals
  - memory copy events
  - gaps (CPU launch / synchronization overhead)
